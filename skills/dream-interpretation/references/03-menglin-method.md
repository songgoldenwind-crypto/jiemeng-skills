# 《梦林玄解》方法提炼

本文是对用户提供的 1993 年扫描本所作的原创工作法提炼，不是全书转录。它帮助组织梦境和检索结果，不证明传统梦兆具有现代实证预测力。版本、页码和 OCR 边界见 [05-source-registry.md](05-source-registry.md)。

## 从单象转向全梦

附录“梦变”一节强调，一梦可以多次迁化，解释者需要知道前后、始终和转折。这与本 Skill 的事件链方法一致：

```text
起始状态 → 关键动作 → 对象变化 → 结果 → 醒后感受
```

处理时遵守以下顺序：

1. 先找推动结局的主动作，不先给名词贴固定标签。
2. 再记录关键对象由什么变成什么。
3. 如果起初状态与结局方向不同，转化过程比静态符号更重要。
4. 梦者只记得中间一段时，明确降低结论强度，不替他补齐开头或结尾。

## 状态和转化词典

扫描本附录把“鲜美开明”与“污秽倾晦”作为传统分类轴，但紧接着又要求检查状态是否反转。转化可按下表记录：

| 起初状态 | 后续变化 | 传统阅读方向 | 现代语境可观察的结构 |
|---|---|---|---|
| 明亮、完好、新整 | 转暗、损坏、零落 | 传统上作“好中藏变”处理 | 对失去、变数或期待落空的担心 |
| 浑浊、污损、枯败 | 转清、修复、复苏 | 传统上作“困中有解”处理 | 从失控走向恢复或重新获得掌控 |
| 可怕、奇异、夸张 | 醒前自行消散 | 不只凭开头判定 | 强烈情绪被梦本身释放 |
| 喜悦、顺利 | 随即哭泣、受阻 | 以完整变化链为准 | 对成功后风险或不配得感的加工 |

这些只是结构化读法。不得把“清”、“脏”、“新”或“破”单独写成现实必然的吉凶。

## 梦者、关系与现实处境

书中“贵贱有别”用的是古代身份秩序。现代处理不沿用尊卑判断，只提取其中可用的原则：同一梦象需结合梦者真实的角色、当前任务和个人联想，不能把原文中的帝王、仕子、商贾、女子等结果直接套到现代人。

“梦寄”讨论了梦中事件落在自己或他人身上的情况。本 Skill 只用它提醒先分清：

- 谁做的梦；
- 梦中谁在行动或承受结果；
- 梦者与该人在现实中的关系；
- 用户是在问自己的感受，还是试图确定他人的现实状态。

梦不能证明他人将发生什么，也不能证明他人的真实意图。

## 传统时令与伦理层的使用边界

附录还有天地、时令、干支生克、星宿、邪正和敬肆等占梦说法。它们属于该书的历史宇宙观和道德观，当前 Skill 没有已校验的时令换算模型，因此：

- 不根据梦的日期自动加减吉凶；
- 不从用户身份、品行或所谓“德行”推断其应验资格；
- 可以把梦后的应对方式作为现实建议，但理由应来自可行的行动，不是趋吉避凶的承诺；
- 用户明确询问这套历史方法时，可作文献说明，必须标明“书中传统说法”。

## 何时应当降级或停止占断

附录列出“不占”和“不验”条件。不照抄它的超自然前提，可将其改写成下列信息质量门槛：

- 梦明显由醒前已知的担忧、睡眠环境或身体不适触发时，优先解释这些触发因素；
- 梦在关键转折前被惊醒，或前后已遗忘时，不对未完成的结局作强判断；
- 叙述者主动缩放、改写或在两种相反结论间摇摆时，先回到原梦细节；
- 传统条目本身不完整、OCR 可疑或来源冲突时，标记“文本证据不足”。

## 跨资料冲突的处理

内置古典辞典与《梦林玄解》本地 OCR 是两个资料通道，不得把文本重复误当作两份独立验证。

1. 分别记录每个候选的来源、页码、文本完整度和场景匹配度。
2. 亲眼核对的 PDF 页图比未核对 OCR 更可靠；语义更贴合梦境的条目比只共享一个名词的条目更相关。“文本可靠度”和“匹配度”必须分开。
3. 两条目可以同时解释梦的不同阶段时，沿事件链分开写。
4. 若对同一场景给出相反结果，不投票、不强行平均；直接报告冲突和各自限定条件。
5. 只有 OCR 定位而未核页图时，应用概括，不用引号冒充精确原文。
