# 私有完整知识资源边界

## 运行时结构

本机私有完整版把扩展正文知识直接保存在已安装 Skill 的以下内部目录：

```text
references/.private/extended-corpus/
├── corpus.jsonl
└── manifest.json
```

`corpus.jsonl` 的每条记录只包含不透明块标识、正文和帮助检索的规范化文本。它不包含作者、页码、原始文件路径或识别工具信息。`manifest.json` 只保留数量和内容摘要，用于在每次检索前验证内部知识没有缺失或被意外改动。

`search_menglin.py` 默认只读上述 Skill 内部目录。内化完成后，原始资料和旧的 Skill 外部索引都不是解梦运行时依赖。

## 建立与迁移

已有完整的旧本机索引时，在已安装 Skill 内运行：

```bash
python3 scripts/internalize_menglin_index.py
```

该脚本先检查旧索引的完整性，再只把完整正文知识写入当前 Skill 的私有目录。如果尚未建立旧索引，`build_menglin_index.py` 会从用户合法持有的资料直接构建同样的 Skill 内部完整知识。

使用顶层安装器的 `--force` 更新 Skill 时，`references/.private/` 会被原样保留。因此代码更新不会把已内化的完整知识删掉。

## 公开分发边界

公开 Git 仓库和公开 `.skill`/`.zip` 包不包含私有完整正文。`.gitignore` 与打包器独立排除 `references/.private/`，避免私有内容在升级或发布时被意外公开。这个分发限制不改变本机已安装 Skill 是否自包含：只要 `--status` 通过，它的完整正文知识就在 Skill 内部。

## 用户可见回答边界

内部搜索只为了得到更精确的内容判断。解梦回答不得显示或暗示：

- 书名、作者、版本或出版信息；
- 卷册、页数、页码或任何定位信息；
- 文件名、路径、文件类型或文件指纹；
- 识别、建索引、搜索、命中、校验等内部过程。

用户只看到传统内容的精确对应、近似对应、条件冲突或无直接对应，以及与完整梦境相关的有限综合解释。
