## 检索词组合

查完整内部知识时，优先以“对象 + 动作 + 状态/方向”组合，再逐步放宽：

```text
蛇 + 入门 + 咬人
水 + 浑浊 + 变清
书 + 丢失 + 寻回
房屋 + 先完好 + 后倒塌
```

第一次无命中时，先替换古今词（如“房子/屋/宅”），再删去次要限定词。不先用“吉”或“凶”搜索，否则会得到大量与原梦无关的结果。

检索结果只返回匹配强度与文本片段，不返回作者、书名、页码、文件或识别过程信息。
