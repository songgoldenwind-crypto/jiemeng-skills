## 附录

- **占繇——解梦的原则：** 目录标书页 300，扫描实际见书页 301（PDF 第 309 页）起。包括时令宇宙观、梦者处境、鲜明/污晦状态、状态反转、全梦迁变、关系主体以及传统的“不占/不验”条件。
- **梦文化综论：** 书页 305（PDF 第 313 页）起。包含梦的分类，以及语言、身体感受、天象、山川草木、飞禽走兽、居所与日常物品等象征主题。这一部分用于扩展检索词，不自动升格为普遍心理规律。

## 检索词组合

查全书 OCR 时，优先以“对象 + 动作 + 状态/方向”组合，再逐步放宽：

```text
蛇 + 入门 + 咬人
水 + 浑浊 + 变清
书 + 丢失 + 寻回
房屋 + 先完好 + 后倒塌
```

第一次无命中时，先替换古今词（如“房子/屋/宅”），再删去次要限定词。不先用“吉”或“凶”搜索，否则会得到大量与原梦无关的结果。

检索词太通用时，可按上表使用 `--pdf-page-from` 和 `--pdf-page-to` 限定部类。例如只查“梦变”附录：

```bash
python3 scripts/search_menglin.py --query "梦变" \
  --pdf-page-from 309 --pdf-page-to 312
```
